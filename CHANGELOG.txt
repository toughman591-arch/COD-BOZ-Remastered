COD Black Ops Zombies (mobile) - Kino BO1 Remaster v2.7
Built 2026-10-09 from: app-release (1)(5)(1).apk + blackops_atitc.dz + ximages.zip (BO1 PC textures)

GETTING THE FILES (on your PC)
------------------------------
The full files are too big to send here, so this package is a patch.
1. Unzip the package into a folder.
2. Copy your ORIGINAL blackops_atitc.dz and your ORIGINAL app-release (1)(5)(1).apk
   into the same folder. The APK can have any file name; the patcher finds it by checksum.
3. Double-click APPLY.bat, or run: python apply_patch.py
   You get:
     output\blackops_atitc.dz                MAIN BUILD (HD), 344,532,943 bytes
     output\SAFE\blackops_atitc.dz           FALLBACK, exactly the original size
     output\BOZ_Kino_BO1_Remaster_v1.apk     the app. Only change: remastered 115 song.
                                             Re-signed with a debug key.
   The patcher checks every output against my build's checksum before writing it.
set_fov.py   Change the FOV in the HD .dz:   python set_fov.py output\blackops_atitc.dz 70

INSTALL
-------
1. Back up your current blackops_atitc.dz and your save, if you care about it.
2. Uninstall the old app. The new APK is signed with a different key, so Android won't
   install it over the old one.
3. Install output\BOZ_Kino_BO1_Remaster_v1.apk.
4. Copy output\blackops_atitc.dz (HD) into Android/obb/com.activision.boz/, replacing the old one.

    - DEAD OPS CRASH: solo Dead Ops closed the game while loading. Most likely cause: game memory. This Mali
      build stores every see-through texture uncompressed (Mali phones can't use the original ATC format), which
      makes those textures 4 times bigger. Dead Ops has a lot of them: about 66 MB uncompressed (about 21 MB
      just for its shared in-game set, plus 2-7 MB per arena), against about 17 MB in the original data. The

      while loading.
    - FIX: the game's memory pool is now 256 MB (one number in the game's own settings inside boz.s3e, the
      line "MemSize = ExtraMemorySize + ..."). Nothing else changed; every other mode just has more room.
